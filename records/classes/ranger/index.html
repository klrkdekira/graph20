Core Ranger Traits Becoming a Ranger ... As a Level 1 Character - Gain all the traits in the Core Ranger Traits table. - Gain the Ranger's level 1 features, which are listed in the Ranger Features table. As a Multiclass Character - Gain the following traits from the Core Ranger Traits table: Hit Point Die, proficiency with Martial weapons, proficiency in one skill of your choice from the Ranger's skill list, and training with Light and Medium armor and Shields. - Gain the Ranger's level 1 features, which are listed in the Ranger Features table. See the multiclassing rules in “Character Creation” to determine your available spell slots. Ranger Class Features As a Ranger, you gain the following class features when you reach the specified Ranger levels. These features are listed in the Ranger Features table.
