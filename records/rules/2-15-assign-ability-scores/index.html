Assign Ability Scores

Rule

SRD 5.2.1 · Character Creation §2.15 · Assign Ability Scores · lines 1022–1043

Indexed facts

section
2.15

Source text

Once you've generated six scores, assign them to Strength, Dexterity, Constitution, Intelligence, Wisdom, and Charisma, keeping in mind your class's primary ability. Fill in the ability modifiers as well. If you're using the Standard Array option, consult the Standard Array by Class table for suggestions on where to assign scores for your character's class. The table puts the highest scores in a class's main abilities. If you used a different method to generate the scores, you may still use this table to guide where you place your highest and lowest scores.
