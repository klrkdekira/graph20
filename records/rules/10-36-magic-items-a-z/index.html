Indexed facts

section
10.36

Source text

Magic items are presented in alphabetical order. If a magic item description capitalizes a creature's name and presents it in bold type, that's a visual cue pointing you to the creature's stat block. Unless the text states otherwise, the stat block is in “Monsters.” How to read and use a stat block is explained in “Monsters.”
